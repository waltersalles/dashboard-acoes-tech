# 📊 Dashboard Interativo de Ações Tech - Google, Apple, Microsoft, Nvidia

Este projeto foi desenvolvido com Python e Dash para visualizar de forma interativa os preços de fechamento das ações de grandes empresas de tecnologia como Google (GOOGL), Apple (AAPL), Microsoft (MSFT) e Nvidia (NVDA).

## 🚀 Funcionalidades

- Visualização dinâmica de preços de ações em gráficos interativos com Plotly
- Filtros por intervalo de datas (ex: últimos 3 meses, últimos 6 meses, etc.)
- Seletor de ações para exibir individualmente ou comparar empresas
- Interface web interativa com Dash

## 🧰 Tecnologias utilizadas

- Python
- Dash
- Plotly
- yFinance (Yahoo Finance API)

## 📦 Instalação
